# Phase 2: evidence data and spatial model

Live import status (18 October 2026): this WildTrack database is at `0006_research_evidence`. The source package was imported and audited: 6 study regions, 29 thematic zones, 2 datasets, 94 wildlife occurrences and 97 occurrence-region memberships. All saved source identifiers, licences and links matched the package, and all geometries were valid. The separate Field Records page displays these records at `/field-records`.

Phase 2 provides the database and API path for dated, sourced wildlife observations and map overlays. It keeps sightings separate from simulated animal movement. The new records do not have an animal tag, confidence score, or invented path.

## Thematic overlays

`data/research/phase2-landcover-zones.geojson` is generated by `scripts/derive_phase2_landcover_zones.py` from the Phase 1 study-region polygons and [ESA WorldCover 2021 v200](https://esa-worldcover.org/en/data-access) at 10 m resolution. It contains up to one dissolved overlay per region and class:

| Overlay | WorldCover classes | Interpretation |
|---|---:|---|
| Tree cover | 10 | Modelled tree-cover pixels |
| Shrubland | 20 | Modelled shrubland pixels |
| Grassland | 30 | Modelled grassland pixels |
| Cultivated land | 40 | Modelled cropland pixels |
| Built-up footprint | 50 | Modelled built-up pixels, not a complete settlement boundary |
| Bare or sparse cover | 60 | Modelled bare/sparse cover, not proof of rock |
| Water or wetland | 80, 90 | Modelled permanent water or herbaceous wetland |

The crop has no DEM. It does not support elevation, slope, waterfall, rocky-ground, landslide-susceptibility or danger zones. [GSI's 1:10,000 map viewer](https://bhusanket.gsi.gov.in/NLSM_10K_Map.html) lists available map titles, but this research package has no georeferenced Ooty susceptibility polygons. The [Copernicus GLO-30 public elevation model](https://registry.opendata.aws/copernicus-dem/) is a viable next source; it is a digital surface model and needs a separate, documented slope derivation and validation. Any future slope overlay must be labelled as terrain steepness, not landslide probability. Do not fill these gaps with hand-drawn polygons.

The saved raster crop covers all six current study geometries; each generated feature records 100% raster coverage for its region. Classes below 1,000 m² are excluded and outlines are simplified by about 5 m for display. The class values are model predictions from 2021, not current land status or confirmed wildlife habitat.

## PostgreSQL model

Alembic revision `0006_research_evidence` adds the following tables without changing operational animals, zones or simulated observations:

- `study_regions`: sourced study extents and their derivation metadata.
- `thematic_zones`: normalized region-to-class overlays, source version, resolution, licence, area and PostGIS geometry.
- `research_datasets`: DOI, title, dataset citation, dataset-level licence and source metadata.
- `wildlife_occurrences`: dated source events, stable provider record ID, source dataset, point, geodesic uncertainty polygon, individual record licence, taxon and quality flags.
- `occurrence_region_memberships`: many-to-many links from each event to all containing regions, with the uncertainty-edge flag.

The schema uses foreign keys, unique source keys, check constraints, B-tree indexes for species/date and licence queries, and GiST indexes for spatial operations. Dataset-level licences and record-level licences are both retained because GBIF aggregates records with different reuse terms. The source event date string is preserved next to its normalized UTC timestamp so date-only records remain auditable. `recorded_at` records when WildTrack ingests the event.

The operational `observations` table remains separate. Field Records reads historical sightings with `GET /api/v1/research/occurrences` and study extents with `GET /api/v1/research/areas`; add `?land_cover=true` to include the thematic overlays. The dedicated `/field-records` page uses small dots, shows provenance after selection and starts with land cover hidden. Its filters cover region, species, taxonomic group, year and whether the uncertainty circle stays inside a region.

## Import

Generate the overlay before migrating/importing:

```powershell
backend\venv\Scripts\python.exe scripts\derive_phase2_landcover_zones.py
```

From the repository root, apply the schema migration to the intended database:

```powershell
backend\venv\Scripts\python.exe -m alembic -c backend\alembic.ini upgrade head
```

Return to the repository root and inspect the import plan:

```powershell
backend\venv\Scripts\python.exe scripts\import_ooty_research_data.py
```

The importer defaults to dry-run. It writes only when explicitly passed `--apply`, and upserts by stable region code, zone code, dataset key and `(source_system, source_record_id)`. It updates region membership links for each upserted source row inside one transaction. The revision and importer do not clear existing operational animals, zones or observations.

After applying the import, run the read-only audit from the repository root:

```powershell
backend\venv\Scripts\python.exe scripts\verify_ooty_research_data.py
```

It checks the source IDs, record licences, study regions, zones, region memberships and geometry validity against the saved research package. It exits with a nonzero status when the import is incomplete.

## Source and reuse limits

The final source-screened set contains 94 public GBIF events across 40 species. 49 have their full coordinate-uncertainty circle within a study region; 45 have circles that cross a region edge. Keep the edge flag visible to users. The region counts overlap and are uneven.

79 record licences are CC BY-NC 4.0, so the imported data layer is limited to non-commercial use with attribution. Preserve `license_uri`, dataset DOI/citation and source URL in any export or display. No expert taxonomic review has been done. These records show where and when contributors reported a species; they do not identify 94 distinct animals and do not constitute current positions or movement tracks.

The five Survey of India forest extracts clipped to landmark search areas are WildTrack study extents, not legal reserve boundaries. The Mukurthi GatiShakti 2024 snapshot area differs by 4.69% from the source-reported 78.46 km². Reconcile that shape before operational or conservation decisions.
